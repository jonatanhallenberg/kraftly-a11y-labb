# kraftly-portal

Customer portal for Kraftly. Delivered by Webbmakarna AB 2026-06-30.

## Getting started

    npm install
    npm run api      # mock-API på :4000
    npm run dev      # appen på :5173

## Tester

    npm test         # watch-läge
    npm run test:run # kör en gång och avslutar – det CI vill ha
